# Content Engine Strategy

## 1. Description Hierarchy
- `SHORT_DESC`: Maximum 60 chars. Brand + Noun + Key Attribute.
- `MOBILE_DESC`: Bulleted highlights optimized for small screens.
- `LONG_DESC1`: Comprehensive paragraph covering all features.
- `INVOICE_DESC`: Truncated, highly abbreviated description (max 30 chars) for legacy systems.

## 2. Generation
These are NOT generated by asking an LLM "write a description". They are generated using deterministic templates populated by the structured attributes we extracted earlier.
